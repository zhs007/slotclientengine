## 结果

任务 147 已完成代码、资源与 L2 自动化。game002 现在会在表现 mutation 前读取
`docs/crave/gameresults.json` 同结构 round，并严格编译：

```text
BaseGame terminal settled scene
-> bg-triggerfg WL win
-> BG_FG
-> 10 次 selective fg-spin
-> 每步 AF（如有）后处理 CO（如有）
-> terminal fg-win CN collect（不 remove）
-> BigWin complete
-> FG_BG
-> BaseGame 保留 FG final scene
```

  feature position 和 CO relocation 全部在动画前校验。

- AF 使用 `free-spins` ImgNumber raw digits，播放 `Feature -> Change` 后提交 AF -> CN。
- CO source 只接受 post-AF scene 的 WL/CN，复用整批 transfer transaction，提交后
  source 为 BN、target 接收 occurrence/value、CO 为 CN。
- 最终 `fg-win` 复用 CN collect，但 `removePositions=[]`；退出等待 popup
  `complete`，两次 mode transition 都不重建业务 reel。
