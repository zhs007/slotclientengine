# underwater3ddemo

Three.js 竖屏海底环境样片。当前基线包含水体颜色衰减、极弱全局折射、一层宽柔环境光域、一束
软边主光和远中近三层低浓度动态水雾；不包含海面、海床、气泡、微粒、symbol、鱼群、沉船、
洞穴边框或珊瑚。摄像机保持固定，动态只来自水体内部的低频明暗流动。主光和三层水雾共享一张
1024×1024 无缝 RGBA 数据贴图：RG 保存两种尺度的密度，BA 保存二维流向；贴图不参与背景水色，
避免重新产生海面映射的错觉。运行时贴图采用带完整 mipmap 的 UASTC KTX2，并使用
Three.js 本地依赖中随生产包输出的 Basis JS/WASM 转码器，不依赖 CDN。后续效果以单一元素逐步加入。

第二张无缝 KTX2 聚光数据贴图不直接显示在画面中，只作为宽主光与模型鱼皮焦散的内部驱动数据。
同一光场会轻微调制主光的弯曲、扩散和密度，不把纹理本身画成顶部水纹平面或规则光柱。

水体中只放置四组低数量 3D 气泡球壳。气泡使用透明薄膜、Fresnel 边缘和双高光表达体积，不使用
全屏粒子；不同深度分别控制尺寸、清晰度、上升速度和横向漂移，以提供前中后景空间参照。

上半部与两侧加入两组程序化远景鱼群剪影。鱼形由 instanced quad 的 SDF shader 生成，不依赖图片或
模型；15 条远景鱼共享一次 draw call，并按两种深度、速度、尺寸和透明度缓慢横向游动。剪影保持低
对比度并参与水雾，中央 symbol 区不增加实体装饰。

场景暂时放置一排 5 个同尺寸、同深度的动画河豚，作为正式 symbol 层的首行原型。所有实例共享同一份
GLB、几何、材质与贴图，只通过不同 `idle` 相位、速度和极弱浮动打散同步感。模型使用真实的顶部柔光、
水体补光和弱轮廓光，并参与场景雾化；气泡通过深度测试从模型前后经过。水面 KTX2 光场还会以很低的
强度投射到朝上的鱼皮上；运行时通过原始底色遮罩保护眼白、瞳孔、鼻孔与嘴部，不让焦散削弱面部表情。
非深度感知的主体积光平面保持在所有 symbol 后方，避免透明光层覆盖模型后形成重影。

该 demo 的目标是先验证纯海底氛围与移动端实时渲染路线。独立的 `viewer.html` 仍可用于检查后续加入
场景的 GLB 资源及其动画。

```bash
pnpm --filter underwater3ddemo dev
```

定向验收：

```bash
pnpm --filter underwater3ddemo typecheck
pnpm --filter underwater3ddemo lint

```
